# 软件架构与算法说明

## 1. 数据流程

1. `generate_cw` 或 `generate_fmcw` 生成长度为 N 的复基带信号；
2. 根据 UCA 阵元坐标和入射方向计算八通道导向矢量；
3. 合成 `8 × N` 阵列快照，并按设置信噪比加入复高斯白噪声；
4. 对八通道数据进行常规波束形成，得到单路复数输出；
5. 对波束形成结果进行多相 FIR + FFT 通道化；
6. 计算阵列样本协方差矩阵，并通过特征分解获得噪声子空间；
7. 在方位角、俯仰角网格上计算 MUSIC 空间谱；
8. 输出 CSV、方向图、通道化频谱和二维空间谱。

## 2. 阵列模型

阵元位置记为 `r_m`，信号方向单位向量记为 `u(az, el)`。第 m 个阵元的理想
窄带接收导向量为：

```text
a_m(az, el) = exp(-j 2π/λ · r_m^T u)
```

阵列半径、载波频率、信号方向和噪声强度均可通过配置文件修改。

## 3. 波束形成

常规波束形成采用：

```text
w = a(az0, el0) / M
y[n] = wᴴx[n]
```

其中 M 为阵元数，`az0`、`el0` 为波束指向。方向图通过遍历不同方位的导向矢量
并计算 `|wᴴa|` 得到。

## 4. 通道化

通道化器使用长度为 `M × P` 的原型低通 FIR。每 M 点取一帧，完成多相分解和
相位累加后进行 M 点 FFT。默认参数为 64 个频率通道、每相位 8 个抽头。

该模块用于验证算法和数据接口，后续 FPGA 实现需要重新确定系数位宽、输入位宽、
FFT 缩放、舍入和饱和策略。

## 5. MUSIC 测向

八通道数据首先计算样本协方差矩阵：

```text
R = XXᴴ / N
```

对 R 进行特征分解，取较小特征值对应的特征向量组成噪声子空间 `E_n`。空间谱为：

```text
P(az, el) = 1 / (aᴴ E_n E_nᴴ a)
```

程序在指定角度网格上搜索最大谱峰，并将其作为估计方向。

## 6. 后续软硬件划分

建议实板阶段首先在 PL 端完成 RFDC 接口、通道同步、校准、FIR/FFT 和 DMA，
在 PS 端完成参数控制、结果显示和 MUSIC 软件基线。根据实际吞吐量与延迟测试结果，
再决定是否将协方差累加或谱搜索迁入 PL。
