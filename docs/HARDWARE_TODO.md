# ANTSDR T510 实板适配清单

## 1. 开发环境

- [ ] 确认 T510 硬件版本、XCZU28DR 完整料号及板级资料；
- [ ] 确认 Vivado/Vitis 2022.2 版本和补丁；
- [ ] 准备与板卡版本匹配的约束文件、BSP 和启动文件。

## 2. RF Data Converter

- [ ] 配置 ADC/DAC Tile、Slice、采样率、插值/抽取和数字混频器；
- [ ] 确认 AXI-Stream 位宽、每拍样本数、I/Q 排列和符号格式；
- [ ] 完成 RFDC 相关时钟、复位和状态监测；
- [ ] 完成综合、实现、时序检查和 DRC；
- [ ] 生成可追溯的 bitstream 和 XSA。

## 3. 时钟与 MTS

- [ ] 配置板上参考时钟和 SYSREF；
- [ ] 在 Vitis 中完成 RFDC MTS 初始化；
- [ ] 记录各 Tile 的延迟和偏移；
- [ ] 多次冷启动验证确定性时延；
- [ ] 使用同源射频信号测量八通道相位一致性。

## 4. 数据通路与驱动

- [ ] 完成 `XRFdc` 初始化、Mixer/NCO、FIFO 和状态读取；
- [ ] 建立 AXI DMA 与 DDR 环形缓冲；
- [ ] 处理缓存一致性、帧边界、超时和丢帧；
- [ ] 定义 PS/PL 控制寄存器和版本信息；
- [ ] 测量持续吞吐量、处理延迟和长时间运行稳定性。

## 5. FPGA 算法实现

- [ ] 确定 FIR、FFT 和波束形成的数据位宽；
- [ ] 确定舍入、饱和和级间缩放策略；
- [ ] 使用软件生成的 CSV 数据进行逐级对比；
- [ ] 验证 AXI 背压、复位、跨时钟域和帧同步；
- [ ] 记录资源占用、最高时钟频率、误差和延迟。

## 6. 阵列与射频校准

- [ ] 核对天线坐标、编号、极化、馈线和通道顺序；
- [ ] 测量各通道随频率变化的增益、相位和群时延；
- [ ] 测量阵元方向图及互耦；
- [ ] 建立复数幅相校准表；
- [ ] 在已知角度下完成多组测向误差测试。

## 7. 系统测试

- [ ] 区分仿真数据、离线采集数据和实时数据；
- [ ] 保存原始 IQ、运行参数、校准版本和时间戳；
- [ ] 完成不同频率、信噪比和入射角度的测试；
- [ ] 验证重启、断连和异常输入后的恢复能力；
- [ ] 汇总角度误差、刷新率、带宽、资源和功耗数据。
